# Claims Operations Manual

This manual sets out who may approve claims, how catastrophe events are run, and when a claim is referred to the Special Investigations Unit (SIU). It applies to every region unless a regional addendum says otherwise.

## Catastrophe response procedure

Run these steps in order once the regional weather desk confirms a catastrophe (CAT) event. Sub-steps are run in the order shown.

1. Declare the event
   1. Confirm the event with the regional weather desk
      - Record the desk's reference number
      - Note the expected landfall or peak time
   2. Open a CAT code in ClaimsCenter
      - Use the format CAT-<year>-<region>-<sequence>
      - Link every new claim from the affected postcodes to the code
   3. Notify the Head of Claims

   The declaration must be made within 4 hours of landfall; a late declaration is logged as a control breach.

2. Stand up the response team
   1. Appoint a CAT lead from the Senior Adjuster pool
      - The lead must not be on the on-call rota that week
   2. Pull field adjusters from unaffected regions
      - Ask the neighbouring region first
      - Cap the loan at 20% of that region's adjusters
   3. Book the mobile claims units
3. Triage incoming claims
   1. Tag each claim Red, Amber or Green
      - Red: uninhabitable home or injured person
      - Amber: major damage, home still habitable
      - Green: minor or cosmetic damage
   2. Call every Red claimant within 24 hours
   3. Send Green claimants the self-service link
      - The link expires after 30 days

   Triage tags may be changed by the CAT lead only.

4. Raise emergency payments
   1. Pay Red claimants an advance of up to 3,000 in local currency
      - The advance is deducted from the final settlement
   2. Pay temporary accommodation directly to the provider
5. Run the daily stand-up
   1. Review the Red queue first
   2. Re-balance adjusters across postcodes
      - Move adjusters only between postcodes in the same CAT code
   3. Publish the daily CAT report by 18:00 local time
      - Send it to the Head of Claims
      - Send it to Reinsurance
      - Archive it in the CAT code's folder
6. Close the event
   1. Confirm that no Red claims are open
   2. Return loaned adjusters to their home regions
   3. Write the lessons-learned report within 30 days
      - Include the time from landfall to declaration
      - Include every control breach

   Closing the CAT code freezes its emergency-payment budget.


## SIU referral criteria

Refer a claim to the Special Investigations Unit when it shows any red flag below, or three or more amber flags from different groups.

- Policy
  - Red flags
    - Policy incepted less than 30 days before the loss
    - Cover increased less than 14 days before the loss
  - Amber flags
    - Several policies taken out at the same address within a year
    - Premium paid in cash by a third party
- Claimant
  - Red flags
    - Claimant is on the industry fraud register
    - Claimant refuses a recorded statement
  - Amber flags
    - Unusually detailed knowledge of the claims process
    - Pushes for a quick cash settlement
- Loss
  - Red flags
    - Fire started in more than one place
    - Stolen vehicle recovered burnt out within 48 hours
  - Amber flags
    - No police report for a theft
    - Receipts all from the same seller
