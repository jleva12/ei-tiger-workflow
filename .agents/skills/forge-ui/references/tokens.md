# Forge tokens

Source of truth: `src/index.css` (light values in `:root`, dark in `.dark`,
utilities generated by `@theme inline`). Every colour below is available as
`bg-*`, `text-*`, `border-*`, `ring-*`, `fill-*`, etc. — e.g.
`text-subtle`, `bg-status-running`, `border-danger-border`. Dark mode is the
`.dark` class on `<html>`; the tokens switch automatically.

Choosing:

- Body text `text-foreground`; secondary `text-muted-foreground`; hints,
  timestamps, placeholders `text-subtle`.
- Status colour comes from components (`StatusBadge`, `StatusSymbol`,
  `Chip`, `RunStateIcon`) — use the tokens directly only when building
  something those can't express.
- Errors: `ErrorCallout` / `Alert variant="error"`; for custom pieces
  `bg-danger-surface border-danger-border text-danger-foreground`.

## Type

Geist variable font. Body is 13px.

| Utility | Size |
| --- | --- |
| `text-lg` | 18px — occasional headings (line-height 1.5) |
| `text-sm` | 14px — the `--text-ui` size for primary UI text |
| `text-xs` | 12px — labels, buttons, table text |
| `text-2xs` | 11px |
| `text-3xs` | 10px |
| `text-4xs` | 9px |

Buttons use 12px / weight 450. Prefer these over arbitrary sizes, and when a
one-off size is needed write it in rem (`text-[0.8125rem]`, 13px), never px:
the user's text-size preference scales the root font size, so px text would
stay small while everything else grows.

## User preferences

`UserPreferencesProvider` (`@/lib/user-preferences-provider`) sets these on
`<html>`; the theme responds, so components only need to use tokens:

| Set on `<html>` | Effect |
| --- | --- |
| `--forge-font-scale` | root font size × scale: every rem size (text and Tailwind spacing) |
| `data-forge-density="compact"` | `--spacing` 0.25rem → 0.21875rem; `--forge-row-height` 45px → 34px |
| `data-forge-contrast="more"` | darker `--muted-foreground`, `--subtle`, `--nav-foreground`, `--border`, `--input` (lighter in dark) |
| `data-forge-motion="reduce"` | animations and transitions off |

List rows that should follow density use `h-(--forge-row-height,45px)`. DataTable follows the
preference itself (it reads `data-forge-density`) unless given a `density` prop.

## Radii

Use the variables (`rounded-(--radius-…)`), not `rounded-md` etc.:

| Variable | Value | Typical use |
| --- | --- | --- |
| `--radius-chip` | 4px | badges, chips |
| `--radius-item` | 5px | menu items |
| `--radius-soft` | 6px | small inset surfaces |
| `--radius-control` | 7px | buttons, inputs, tabs, toggles |
| `--radius-card` | 8px | cards, panels |
| `--radius-band` | 9px | menus, popovers, status bands |
| `--radius-dialog` | 16px | dialogs, sheets |

## Elevation

`shadow-(--shadow-float)` (menus, popovers), `shadow-(--shadow-raised)`,
`shadow-(--shadow-paper)`, `shadow-(--shadow-tab)`. Outline buttons have no
shadow, by design.

## Utilities

`bg-orb-workspace`, `orb-agent-0` … `orb-agent-4` (avatar gradients),
`scrollbar-dark` (inside the console).

## Container breakpoints

Inside `AppShell` (`@container/shell`), respond with
`@max-[<width>]/shell:` / `@min-[<width>]/shell:` at the established widths:
1700, 1270, 1250, 1050, 900, 800, 760, 600px (600 and 900 are the most
common). Outside the shell container (portaled overlays), use viewport
variants like `max-[600px]:`.

## Focus

A global, unlayered rule gives focused `button`, `a` and `[tabindex="0"]`
a 2px `--focus` outline offset 3px; it deliberately beats `outline-none`.
Inputs use `ring` utilities instead. Override on one element only with the
important modifier (`focus-visible:outline-offset-[-2px]!`).
